# handoff

Pass work from one AI chat to the next without re-explaining: a self-contained note on the way out, a quick check-and-archive on the way in.

**Works with any AI, not just Claude.** A skill is just a set of written rules. Share it with your AI of choice and ask it to fit the skill to you; it will help you edit and revise it until the rules are yours.

**Tested with Claude, GPT and Gemini.**

The skill itself: [skills/handoff/SKILL.md](skills/handoff/SKILL.md)

The story behind it: [Skill "Handoff": Starting a Fresh Chat Without Starting Over](https://cairoglyphics.ai/posts/handoff-fresh-chat-without-starting-over/)

## Install

**Claude Code:**

```
/plugin marketplace add Cairo-Labs/skills
/plugin install handoff@cairo-skills
```

**Claude app (web, desktop or phone):** download [handoff.zip](https://github.com/Cairo-Labs/skills/releases/download/handoff-v1.0.0/handoff.zip) and upload it in the Claude app's Skills settings.

**ChatGPT, Gemini or any other AI:** open [SKILL.md](skills/handoff/SKILL.md), copy everything below the top block (the lines between the `---` markers), and paste it into your custom instructions or a project's instructions.
