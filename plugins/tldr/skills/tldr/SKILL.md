# TLDR: status or close

One command to take stock of a chat. Nothing gets left behind, and I only see what genuinely needs me.

## Pick the mode first

| I say | Mode | The chat afterwards |
|---|---|---|
| "tldr" or "tldr status" | **status** (the default) | stays open |
| "tldr close" | **close** | closed out properly, once nothing blocks it |

Anything that isn't clearly "close" is status. Never close on a guess.

## 1. Sweep (quietly, don't narrate)

- Read back through this chat and sort everything into: done, in progress, open.
- **Check before you report.** "Done" needs proof: the saved file, the finished result, the item on the list. If you haven't checked it, call it "claimed", not done. A recap from memory lists work that's already finished.
- **Document check:** list anything decided or learned here that isn't written down anywhere yet. Test: if this chat closed right now, what would be lost? Write each one down now, or treat it as open.
- **Sort the open items by owner:**
  - Yours (the AI's): anything you can find, check, draft or fix yourself. Do it now, without asking. Only stop for something destructive or hard to undo.
  - Mine: only what needs my judgment, priorities, money, password or hands.
  - If you're not sure whose it is, it's yours: go look first.
- **Every item needs a home.** Anything put off must land somewhere that outlives this chat: a to-do list, a notes file, a handoff for the next chat, or a list of questions waiting on me. Putting things off is fine. Leaving them homeless is not.
- **Keep a short log** of the session where future chats can find it (topic, decisions, what got done, what's still open). Update the same log each time, so even a chat that's abandoned leaves a record.

## 2. Report (one short message)

First line: good, bad, or needs-you. Then:

- **Done:** 1 to 4 bullets
- **In progress:** with current state, or "nothing"
- **Handled during the sweep:** one line, only if anything
- **Needs you:** how many decisions, or "nothing" (and stop there)

Then show decision 1 straight away.

## 3. Decisions, one at a time

**[1 of 3] Title:** one line on the issue
1. Option: short pro / short con
2. Option: short pro / short con
- **Recommendation:** which one and why, in one sentence

I answer with a number, "later", or my own words. Act on it, confirm in one line, then show the next one. "Later" goes on the list of questions waiting on me. Never show the next decision before the current one is answered, and keep any unanswered one in a one-line reminder at the end of every message until I respond.

## 4a. Status mode: finish

When the decisions are done or I stop: make sure every open item has a home, then end with what's next, what's mine, and what's still open. The chat stays open. Never say "safe to close" in status mode.

## 4b. Close mode: clear blockers, then close

A chat can't close cleanly while any of these are true:
- a job or task you started is still running
- work is unsaved, or saved somewhere temporary that nobody owns
- a bug or to-do that came up here isn't written down
- a decision is still unanswered
- something you promised me in this chat hasn't happened yet

Clear what you can yourself (wait for running work and check its result, save things properly, write things down). If something has to continue elsewhere, write a handoff for the next chat; that counts as cleared. Bring me the rest as decisions; "later" counts as cleared once it's on my list.

**Never ask "all clear to close?" while something is still unowned.** Closing isn't something I approve; it happens once every item has an owner and a home. If something can't be cleared or parked, say so in one line and leave the chat open. Never claim a close that didn't happen.

Then finish the log, mark it final, and confirm in one line: "Closed. Log written, open items parked," plus where the handoff is if there is one.
