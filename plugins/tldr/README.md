# tldr

One command to take stock of a chat: a quick status that keeps the chat open, or a clean close-out that leaves nothing behind.

**Works with any AI, not just Claude.** A skill is just a set of written rules. Share it with your AI of choice and ask it to fit the skill to you; it will help you edit and revise it until the rules are yours.

The skill itself: [skills/tldr/SKILL.md](skills/tldr/SKILL.md)

The story behind it: [Skill "TLDR": One Command to Check In On a Chat or Close It Out](https://cairoglyphics.ai/posts/tldr-status-or-close/)

## Install

**Claude Code:**

```
/plugin marketplace add Cairo-Labs/skills
/plugin install tldr@cairo-skills
```

**Claude app (web, desktop or phone):** download [tldr.zip](https://github.com/Cairo-Labs/skills/releases/download/tldr-v1.0.0/tldr.zip) and upload it in the Claude app's Skills settings.

**ChatGPT, Gemini or any other AI:** open [SKILL.md](skills/tldr/SKILL.md), copy everything below the top block (the lines between the `---` markers), and paste it into your custom instructions or a project's instructions.
