# work-claim

Stop two AI chats or agents from doing the same job at once: check a shared claims list, claim the task, release it with the outcome.

**Works with any AI, not just Claude.** A skill is just a set of written rules. Share it with your AI of choice and ask it to fit the skill to you; it will help you edit and revise it until the rules are yours.

**Tested with Claude, GPT and Gemini.**

The skill itself: [skills/work-claim/SKILL.md](skills/work-claim/SKILL.md)

The story behind it: [Skill "Work-Claim": Stop Two AIs From Doing the Same Job](https://cairoglyphics.ai/posts/work-claim-stop-ai-doing-same-job-twice/)

## Install

**Claude Code:**

```
/plugin marketplace add Cairo-Labs/skills
/plugin install work-claim@cairo-skills
```

**Claude app (web, desktop or phone):** download [work-claim.zip](https://github.com/Cairo-Labs/skills/releases/download/work-claim-v1.0.0/work-claim.zip) and upload it in the Claude app's Skills settings.

**ChatGPT, Gemini or any other AI:** open [SKILL.md](skills/work-claim/SKILL.md), copy everything below the top block (the lines between the `---` markers), and paste it into your custom instructions or a project's instructions.
